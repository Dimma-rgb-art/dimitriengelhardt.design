# Projekt-Regeln — dimitriengelhardt.design

## Vor jedem Design-Task
1. Lies `brand-guidelines.md` vollständig
2. Erstelle einen detaillierten Plan (Struktur, Stil, Sektionen)
3. Präsentiere den Plan und warte auf Freigabe — bevor du Code schreibst

## Skills
Nutze immer diese Skills bei Design- und UI-Aufgaben:
- `frontend-design`
- `ui-ux-pro-max`

## Brand-Kurzreferenz
- **Farben:** `#080808` bg · `#FF3D00` accent · `#F2EDE4` text
- **Fonts:** Space Grotesk (display) · Inter (body) · JetBrains Mono (labels)
- **Radius:** 0–2px — keine Rundungen
- **Ton:** Knapp, direkt, deutsch — kein Marketing-Jargon
- **Akzent:** Sparsam einsetzen, maximale Wirkung

## Workflow
- Statische Sites → reines HTML/CSS/JS in `index.html`
- React/Interaktiv → Next.js App in separatem Ordner unter `Websites/`
- Nach Fertigstellung: `git add`, `git commit`, `git push`
